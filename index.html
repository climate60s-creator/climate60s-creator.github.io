climate-shorts

기후 데이터 쇼츠 제작 도구 · A personal tool for making climate-data YouTube Shorts

소개개인정보처리방침서비스 약관

climate-shorts는 유튜브 채널 '기후 한 컷' 운영자가 개인적으로 사용하는 영상 제작 도구입니다. NOAA, NASA 등 공개된 기후 관측 데이터로 짧은 해설 영상(쇼츠)을 만들고, 운영자가 직접 검토하고 승인한 영상만 운영자 본인의 유튜브 채널에 업로드합니다.

하는 일

  • 공개 기후 데이터(이산화탄소 농도, 지구 평균기온 등)를 내려받아 차트 영상으로 만듭니다.
  • 운영자가 승인한 대본으로 내레이션, 자막을 붙여 쇼츠 영상을 완성합니다.
  • YouTube Data API를 사용해 운영자 본인의 채널에 영상을 업로드하고, 업로드한 영상의 조회수를 확인합니다.

누가 사용하나요

이 도구는 운영자 1인이 자신의 컴퓨터에서만 사용합니다. 일반 사용자에게 제공되는 서비스가 아니며, 다른 사람의 유튜브 계정에 접근하지 않습니다.

English: climate-shorts is a single-user tool run by the owner of the "기후 한 컷" YouTube channel. It uses the YouTube Data API only to upload the owner's own reviewed videos to the owner's own channel and to read view counts for those videos.
