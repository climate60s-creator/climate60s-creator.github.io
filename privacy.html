Privacy Policy · climate-shorts

소개개인정보처리방침서비스 약관

1. 수집하는 정보

climate-shorts는 운영자 본인의 구글 계정으로 로그인할 때 발급되는 접근 토큰(OAuth token)만 사용합니다. 그 외 이름, 연락처 등 개인정보는 수집하지 않으며, 운영자 외 다른 사용자의 정보도 수집하지 않습니다.

2. 사용하는 Google 데이터와 목적

  • YouTube 동영상 관리(youtube.upload): 운영자가 승인한 영상을 운영자 본인의 채널에 업로드하기 위해 사용합니다.
  • YouTube 계정 보기(youtube.readonly): 업로드한 영상의 조회수를 확인하기 위해 사용합니다.

Google API에서 받은 정보는 위 목적에만 사용하며, 광고에 사용하거나 판매하지 않습니다. climate-shorts의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 보관과 공유

접근 토큰은 운영자의 컴퓨터에만 저장되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다. 영상 제작에 필요한 대본 작성과 음성 합성에 외부 AI·음성 서비스를 사용할 수 있으나, 이때 Google 계정 정보나 토큰은 전달하지 않습니다.

4. 권한 철회와 삭제

운영자는 언제든 Google 계정의 서드파티 액세스 설정에서 이 앱의 권한을 철회할 수 있으며, 운영자 컴퓨터의 토큰 파일을 삭제하면 저장된 정보가 모두 지워집니다.

5. YouTube 서비스

이 도구는 YouTube API 서비스를 사용합니다. 관련 내용은 YouTube 서비스 약관과 Google 개인정보처리방침을 참고하세요.
